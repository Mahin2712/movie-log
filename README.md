# 🎬 Movie-Log

A modern movie watch-list & log app built with:
- ⚡ Vite + React
- 🎨 Tailwind CSS
- 🖥️ Electron (desktop app)
- 🎞️ TMDB API

## Features
- Track watched & wishlist movies
- Ratings & sorting
- Clean modern UI
- Offline-friendly (local storage)

## Setup
```bash
npm install
npm run dev
